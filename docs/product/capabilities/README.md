# Carte des capacités

Chaque fichier Markdown décrit une capacité utilisateur ou un groupe. Le frontmatter contient un `id` stable de forme `CAP-…`, composé de segments en lettres capitales ou chiffres séparés par des tirets, un `title` en français et un `parent`. Le parent contient l’identifiant du groupe ou une chaîne vide pour un groupe de premier niveau.

Le corps décrit le comportement actuel, ses règles et ses limites en français. La ligne « Code : » renvoie aux principaux fichiers de l’implémentation.
