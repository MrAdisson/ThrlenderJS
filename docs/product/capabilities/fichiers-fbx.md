Dans **File**, **Import FBX** lit un fichier .fbx local et ajoute le modèle à la scène courante. L’import charge le modèle sans lancer ses animations.

Déplier le groupe dans **Scene** pour sélectionner un maillage et ouvrir **Edit Mode** s’il est statique. Les maillages avec squelette ou cibles de morphing restent importables, et l’interface indique la raison pour laquelle le mode Édition est indisponible. [Modélisation 3D](modelisation.md)
